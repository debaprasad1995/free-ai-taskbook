# Contribute to FreeAITaskbook

Thank you for helping people find useful AI tools without deceptive 'free' labels.

1. Open an issue using **Suggest an AI tool** or **Report inaccurate or outdated listing**.
2. To edit the data, create a fork and change `data/tools.json`. Find the tool by unique `slug`. Match an existing category in `data/categories.json`.
3. Add the official website and official pricing/license source as HTTPS URLs. Describe real use cases and important usage limitations in your own words.
4. Keep `verifiedOn` set to `null` unless **you directly checked** the vendor's official source on the stated date. Do not make review claims for other people's checks.
5. Use `free-credits` for nonrenewing credits, `free-tier` for ongoing limited plans, `free` for truly free offerings, `local-open-source` for actual local/open-source tools, or `free-software` for other free software with licensing caveats.
6. Run `npm run check`; open a pull request. No autogenerated or scraped submissions without human review.

We do not accept paid ranking changes, misleading affiliate links, plagiarism, personal data, or promotional spam. Tool vendors can contribute if they disclose their affiliation.
